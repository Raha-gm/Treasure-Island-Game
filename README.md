# Treasure Island Game

A simple text-based adventure game built with Python.

## About the Project

Treasure Island is a beginner-friendly adventure game where players make choices to explore an island and find hidden treasure.

Every decision leads to a different outcome. Choose carefully to reach the treasure!

## Features

- Interactive text-based gameplay
- Multiple paths and choices
- Different endings
- Conditional statements (`if`, `elif`, `else`)
- User input handling

## Technologies Used

- Python

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in your code editor.
4. Run the following command:

```bash
python main.py
```
